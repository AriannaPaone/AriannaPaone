## Projects

**[Mechanistic Analysis of Grokking in Modular Arithmetic](https://github.com/AriannaPaone/grokking-modular-arithmetic)** · `Python` `PyTorch`\
Reverse engineered 2-layer transformers trained on `(a+b+c) mod 37` after grokking. Fourier probes, logit lens and activation patching show layer 0 assembles the answer in a Fourier basis while layer 1 converts it to output format, and that an apparent staged-computation signal is an artefact of the causal mask.
